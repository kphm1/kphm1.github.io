## Featured Work

### Large-Deformation Wrinkling FEA
Nonlinear finite element modeling of strain-dependent surface instabilities
using COMSOL and physics-based analytical models.

### Analytical Wrinkling & Model Validation
Python-based computational modeling using NumPy, SciPy, and Matplotlib for
analytical prediction, numerical optimization, and model validation.

### Dual Stuffing Box
Mechanical CAD and design-for-manufacturing project incorporating threaded
interfaces, service access, tolerances, and manufacturing documentation.

### High-Pressure Flow Tee
Mechanical design and structural analysis of a high-pressure component using
Fusion 360 and COMSOL.
