OVERVIEW

From Physical Theory to Computational Model

This project was developed in support of a broader research study investigating strain-dependent wrinkling in soft layered systems. The objective was to build an analytical model that could provide an independent physics-based reference alongside experimental observations and nonlinear finite-element simulations.

The Python implementation predicts key instability characteristics, including wrinkle wavelength and amplitude, as loading conditions change. The model combines analytical scaling relationships with numerical optimization to study how effective mechanical properties influence the predicted response.

Because the associated research is ongoing, the public version shown here uses generalized terminology and normalized visualization while preserving the structure of the computational workflow.

RESEARCH CONTEXT

Supporting a Larger Wrinkling Study

The analytical model forms one component of a larger research workflow combining experiments, computational mechanics, and theoretical modeling.

Nonlinear finite-element simulations capture the full deformation behavior numerically, while the analytical model provides a simpler physics-based framework for evaluating expected trends and testing potential mechanical explanations.

Comparing these independent approaches helps distinguish robust physical behavior from effects associated with a particular numerical model or fitting procedure.

VALIDATION STRATEGY

Cross-Checking Independent Models

Rather than relying on a single simulation method, the research workflow compares multiple independent representations of the same physical behavior.

Analytical Model

Provides a computationally inexpensive physics-based prediction of instability trends.

Finite-Element Model

Resolves large-deformation mechanics numerically and captures nonlinear behavior beyond the simplified analytical framework.

Experimental Reference

Provides an independent physical benchmark for assessing whether predicted trends correspond to observed behavior.

Cross-Validation

Agreement and disagreement between methods are used to identify which aspects of the mechanics require additional investigation.

ENGINEERING TAKEAWAYS

What I Learned

Model Complexity Should Match the Question

Analytical models and finite-element models provide different levels of detail. Using both makes it easier to separate fundamental mechanics from numerical complexity.

Validation Matters

A computational result becomes substantially more useful when it can be compared against an independent analytical or experimental reference.

Optimization Requires Physical Interpretation

A numerically good fit does not automatically imply a physically meaningful model. Parameter sensitivity and mechanics still need to be evaluated.

Visualization Improves Model Development

Interactive plotting made it easier to identify parameter sensitivity, compare trends, and communicate the behavior of the model.
